# Python 基礎與 SpendSense

直接開啟 index.html 可播放；課程網站入口為 `/ai-study-club/courses/python-basics/slides/`。

- slides.js：13 張投影片內容、120 分鐘帶課節奏、講師筆記。
- styles.css：16:9 版面、手機與列印樣式。
- app.js：方向鍵、目錄、講師視窗與同步。
- spendsense.png：原始 app.py 上傳 data/sample.csv 後的實際截圖，20 筆、2762 元。

快捷鍵：左右鍵換頁、N 筆記、O 目錄、P 講師視窗、F 全螢幕、B 暫時黑屏。Home / End 跳到首末頁。瀏覽器列印輸出全部頁面。

在網站根目錄執行 `npm run sync:courses` 可同步至 public/；dev 與 build 也會先自動同步。

課前開好原教材的基礎 Notebook、analysis.ipynb、練習骨架和 sample.csv。投影片第 5–12 頁包含實作時間，講解後切到編輯器。講師筆記以 N 顯示，投影時建議用 P 開獨立講師視窗。

每頁底部標示教材檔案與章節，可點開 GitHub；上方「教材 GitHub」開完整教材庫，「教材對照」開網站逐頁對照表。SLIDE_MATERIALS 統一管理每頁的對應資料，變更頁序時需一起更新。
