查核日期：2026-10-28。教學指南已針對本課情境改寫；介面語系與版本可能影響顯示名稱。

- [GitHub：建立 Template repository](https://docs.github.com/en/repositories/creating-and-managing-repositories/creating-a-template-repository)：Template 是 Repo 設定，需在遠端啟用。
- [GitHub：從 Template 建立 Repo](https://docs.github.com/en/repositories/creating-and-managing-repositories/creating-a-repository-from-a-template)：建立自己的新 Repo；本課只複製預設分支。
- [VS Code：Repo、Clone 與遠端](https://code.visualstudio.com/docs/sourcecontrol/repos-remotes)：Git: Clone、Push／Pull 與遠端流程。
- [VS Code：Stage 與 Commit](https://code.visualstudio.com/docs/sourcecontrol/staging-commits)：Diff、暫存、提交與捨棄變更的操作依據。
- [VS Code：Branch](https://code.visualstudio.com/docs/sourcecontrol/branches-worktrees)：建立、切換與 Publish Branch。
- [GitHub：Review PR](https://docs.github.com/en/pull-requests/how-tos/review-pull-requests/reviewing-proposed-changes-in-a-pull-request)：Comment、Approve、Request changes；作者不能 Approve 自己的 PR。
- [GitHub：邀請個人 Repo 的 Collaborator](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/repository-access-and-collaboration/inviting-collaborators-to-a-personal-repository)：擁有者邀請、對方接受後取得權限。
- [GitHub：設定 Pages 來源](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)：Deploy from a branch，可使用分支的根目錄。
